# Roadmap

## Version 1.0 — implemented

- [x] Local-first, dependency-free dashboard
- [x] Page profiles with 35 starter image niches
- [x] Niche-aware image prompt builder
- [x] OpenAI BYOK image generation endpoint
- [x] OpenAI BYOK caption drafting endpoint
- [x] Manual image import
- [x] Browser IndexedDB library
- [x] Facebook-friendly portrait cropping, PNG download
- [x] Content planning reminders
- [x] ZIP export, local data reset
- [x] README, Docker support, GitHub CI

## Version 1.1 — possible enhancements

- [ ] Import/export full workspace restore
- [ ] Search and tagging improvements
- [ ] Provider adapter for other officially supported image APIs
- [ ] Prompt version history and image variants
- [ ] Bulk generation with explicit user review and spending controls
- [ ] Accessibility and responsive UI testing

## Version 2 — subject to platform access

- [ ] Official Meta Page OAuth and permission checks
- [ ] Meta Page publishing with human approval and audit logs
- [ ] Background queue and retries on a user-controlled server
- [ ] Multi-user identity/authentication, roles and quotas
- [ ] Encrypted secret storage and credential rotation
- [ ] Analytics using official, permissioned APIs

**Not promised:** Free provider inference, automatic Meta monetization, direct Muse integration without a documented and permitted API, or guaranteed account growth/revenue.
